# Demo walkthrough

Start the app with `docker compose up --build` from the project folder, then open http://localhost:5174.

1. Sign in as `organizer@trustforge.local` with password `trustforge`.
2. Review the event dashboard and open the judging workspace.
3. Inspect assignments, score normalization, and the integrity review.
4. Verify the event audit history, then open the results and gallery.
5. Look up the seeded certificate `TF-2026-001`.
6. Sign in as `participant1@trustforge.local` to submit a project and follow its PostgreSQL-backed status history.

The event is seeded with six sample projects, four judge accounts, six participant accounts, assignments, evaluations, a small number of votes, and one certificate record. Demo account passwords are `trustforge`.
